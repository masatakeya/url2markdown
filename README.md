# url2markdown

URLを貼り付けると、クエリパラメータを除去してページタイトルを取得し、Markdownリンクを生成するWebツールです。

## 使い方

1. URLを入力欄に貼り付け（またはEnterキー）
2. ページタイトルが自動取得される
3. 生成されたMarkdownリンクをコピー

```
[ページタイトル](https://example.com/page)
```

タイトルの自動取得に失敗した場合は、手動で入力できます。タイトル入力欄でEnterを押すとそのままクリップボードにコピーされます。

## ブックマークレット

`📎 MD Link Copy` のリンクをブックマークバーにドラッグすると、閲覧中のページでワンクリックでMarkdownリンクをコピーできます。このWebアプリを開く必要はありません。

## 機能

- クエリパラメータ・フラグメント（`?...` `#...`）を自動除去
- CORSプロキシ経由でページタイトルを自動取得
- タイトルのリアルタイム編集・プレビュー
- クリップボードへのコピー
