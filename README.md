# url2markdown

URLを貼り付けると、クエリパラメータを除去してページタイトルを取得し、Markdownリンクを生成するWebツールです。

## 使い方

1. URLを入力欄に貼り付け（またはEnterキー）
2. ページタイトルが自動取得される
3. 生成されたMarkdownリンクをコピー

```
[ページタイトル](https://example.com/page)
```

タイトルの自動取得に失敗した場合は「再取得」ボタンで再試行するか、手動で入力できます。タイトル入力欄でEnterを押すとそのままクリップボードにコピーされます。

## ブックマークレット

`📎 MD Link Copy` のリンクをブックマークバーにドラッグすると、閲覧中のページでワンクリックでMarkdownリンクをコピーできます。このWebアプリを開く必要はありません。

## 機能

- クエリパラメータ・フラグメント（`?...` `#...`）を自動除去
- スキームを省略した入力（`example.com/page`）も補完
- 複数のCORSプロキシへ同時にリクエストし、最初に取得できたタイトルを採用
- `<title>` が無い・空のページは `og:title` / `twitter:title` で代替
- Shift_JIS・EUC-JP などのページも文字化けせずに取得
- ボット対策ページやエラーページのタイトル（`Just a moment...` など）は採用しない
- 取得に失敗した場合は「再取得」ボタンで再試行
- タイトルのリアルタイム編集・プレビュー
- クリップボードへのコピー
